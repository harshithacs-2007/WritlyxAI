THE SYSTEM

Generation is only one half of the problem.

The prototype makes the control path visible: capture a style, bind it to a session, authorize a purpose-bound request, generate, then leave a trace.

01 / REQUEST LIFECYCLE
01

Capture

Upload a handwriting sample and create a deterministic prototype style representation.

02

Authorize

Bind user, session, style, purpose, model version, content fingerprint and nonce.

03

Generate

Consume a one-time authorization and create the generation record.

04

Trace

Attach a provenance digest so the output has an associated record.

02 / CONTROL LAYER

Security state, made explicit.

User + sessionStyle access is checked against the active session.

Content bindingThe backend derives a SHA-256 fingerprint for the requested content.
One-time useAn authorization transitions from ACTIVE to CONSUMED.
RevocationRevoked styles invalidate active authorizations.
ProvenanceGeneration metadata is linked by a digest.
